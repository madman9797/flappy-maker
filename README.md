# Flappy Maker Website

## Files
- `index.html` — website
- `style.css` — design
- `game.js` — Flappy Maker Lite
- `downloads/Flappy-Maker-Full.love` — put your real full-game `.love` file here

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload everything in this folder.
3. Open the repository's Settings.
4. Open Pages.
5. Choose "Deploy from a branch", select the main branch and `/ (root)`.
6. Save. GitHub will give you the website address.

## Full-game download
Replace the placeholder `downloads/Flappy-Maker-Full.love` with your actual latest `.love` file. Keep the same filename so the download button works automatically.
